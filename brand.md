# DepositLock mobile brand

Visual direction: quiet, photograph-led rental app. Airbnb-like clarity: large property photography, simple navigation, rounded but restrained cards, one primary action per screen, and compact detail rows. The deposit view answers which property, how much, what status, when, and what action is available. Education belongs on the invitation and agreement terms, not the deposit overview.

Palette: Rich Black `#00050F` for text and main actions; Dim Gray `#64666F` for secondary copy; Bright Gray `#E6EBEF` for edges and quiet surfaces; Misty Rose `#FFE1E1` for reported issues; pale green `#D6FFDF` for secured and returned states. White is the main canvas. The source reference called the green `Aero Blue`; its hex value is green, so the hex is authoritative. The reference spellings `EGEBEF` and `FFEIE1` are interpreted as the valid hex values above.

Typeface: bundled Figtree throughout the app, used consistently for interface copy, amounts, statuses, and countdowns. Numeric values use tabular figures. Keep sentence case, short labels, and direct explanations.

Layout: 420px maximum viewport, 24px page padding, 8px spacing rhythm, 48–56px touch targets, rounded photography, thin borders, and generous breathing room. Desktop shows the phone-width application centred without a drawn phone frame.

Motion: short, directional page entrance and bottom sheet slide; no perpetual animation. Respect reduced-motion preferences. Financial state changes require explicit actions and confirmation.

Tone: calm and concrete. Label every wallet and payment interaction as a browser simulation. Never display an invented Solana transaction or say funds moved on-chain in the prototype.
